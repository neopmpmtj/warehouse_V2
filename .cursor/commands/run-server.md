---
name: run-server
description: Start the CentCompras Django dev server
---

Start the development server for local testing:

1. Ensure the virtual environment is active: `source .venv/bin/activate`
2. Run `python manage.py runserver`
3. Remind the user to use one hostname consistently (`http://localhost:8000/` or `http://127.0.0.1:8000/`) when testing Service Workers
